# Event-Driven Commerce Platform

A production-style distributed commerce platform built to demonstrate
modern backend and DevOps engineering practices.

## Objectives

This project demonstrates:

- Python backend development
- REST APIs
- PostgreSQL
- MongoDB
- Redis
- Apache Kafka
- Microservices
- Docker
- Kubernetes
- GitHub Actions
- Terraform
- Ansible
- Azure
- Prometheus
- Grafana
- Automated testing
- Security
- Load testing
- Fault tolerance
